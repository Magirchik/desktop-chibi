# Bundled pixel fonts

Pixeloid Sans / Pixeloid Sans Bold by GGBotNet, © 2020–2022. Unmodified fonts,
bundled under SIL OFL 1.1; see [Pixeloid-OFL.txt](Pixeloid-OFL.txt) and
[Pixeloid-COPYRIGHT.txt](Pixeloid-COPYRIGHT.txt). Used at the native 9 px grid
(18 px for body text, 27 px for the main heading), without font smoothing.
Both fonts include Cyrillic, so Russian labels use the same pixel shapes.

Source: https://github.com/MixaDoDs/AngelOS-Dotfiles/tree/main/.local/share/fonts/pixel
Author: https://www.ggbot.net/fonts/

## Pixelify Sans

Pixelify Sans by Stefie Justprince / The Pixelify Sans Project Authors.
Unmodified variable font, with Latin and Cyrillic glyphs, bundled under
the SIL Open Font License 1.1; see [OFL.txt](OFL.txt).

Source: https://github.com/google/fonts/tree/main/ofl/pixelifysans
Upstream: https://github.com/eifetx/Pixelify-Sans

Pixelify Sans is kept for the existing application wordmark.

Fonts are loaded once through Qt's application font database. No system installation,
external font service, or network connection is needed at runtime.
