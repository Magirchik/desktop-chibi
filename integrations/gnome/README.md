# Мост правил окон GNOME

Этот необязательный мост нужен для получения ID активного приложения на
GNOME/Wayland. Глобальные хоткеи используют системный портал и работают отдельно.
Мост передаёт только ID и отображаемые имена приложений; заголовки окон, содержимое
и нажатия клавиш не читаются. Интерфейс локальный, на пользовательской D-Bus шине.

Код находится в `desktop-chibi@local/extension.js`. Поддерживаются GNOME 45–50.
Установка для текущего пользователя:

```sh
.venv/bin/python scripts/install_gnome_controls.py
```

Скрипт копирует расширение в
`~/.local/share/gnome-shell/extensions/desktop-chibi@local` (учитывает `XDG_DATA_HOME`),
сохраняет предыдущую версию в `~/.local/share/desktop-chibi/extension-backups` и
пытается включить расширение. Он не устанавливается автоматически с приложением.
Если GNOME ещё не обнаружил новое расширение, выйдите и войдите в сеанс, затем:

```sh
gnome-extensions enable desktop-chibi@local
```

Приложение подключается к мосту автоматически. На вкладке «Экран» выберите режим
правила и добавьте приложения из списка открытых окон. Приложения сравниваются
по ID (WM_CLASS, либо desktop app ID), без учёта регистра и суффикса `.desktop`.
Настройки Desktop Chibi не переключают выбранное активное приложение, чтобы
можно было редактировать правило и видеть его результат.

Отключение:

```sh
gnome-extensions disable desktop-chibi@local
```

При отключении моста чибики с правилами «Только»/«Кроме» скрываются до возвращения
моста или выбора «Во всех приложениях». Ручная видимость сохраняется.

Для проверки без установки:

```sh
node --input-type=module --check < integrations/gnome/desktop-chibi@local/extension.js
```

Изолированная проверка протокола хоткеев (без системного диалога):

```sh
dbus-run-session -- /usr/bin/python3 tests/portal_shortcuts_fixture.py
```
