# Формат набора персонажа

[← На главную](../README.md)

Набор — JSON и соседняя папка изображений. Экспорт в мастерской копирует картинки и проекты слоёв и записывает относительные пути.

```json
{
  "version": 1,
  "name": "Мой чибик",
  "animations": {
    "idle": {"file": "assets/idle.gif", "first_frame": 0, "last_frame": 12, "speed": 100, "pingpong": true},
    "walk": {"file": "assets/walk.png", "width": 32, "height": 32, "frames": 4, "fps": 8},
    "notify": {"file": "assets/notify.png", "width": 64, "height": 64, "frames": 3, "fps": 5, "delays": [100, 200, 300]}
  }
}
```

Состояния: `idle`, `walk`, `fall`, `land`, `drag`, `talk`, `notify`, `success`, `error`. Дополнительные варианты покоя — `idle_1`, `idle_2` и далее. До 32 анимаций. Все состояния необязательны: отсутствующее использует покой или встроенный облик.

Для спрайт-листов кадры читаются слева направо, затем сверху вниз. Размеры должны делить лист без остатка. `fps` — 1–60, `frames` — 1–512. `delays`, если задан, содержит задержку каждого кадра в миллисекундах и имеет приоритет над FPS.

Для GIF используются собственные задержки. `first_frame` — индекс первого кадра с нуля, `last_frame` — исключительная верхняя граница; 0 означает конец файла. Например, 0 / 12 включает первые 12 кадров, которые в интерфейсе обозначены 1–12. `speed` — 25–400 %, `reverse` — обратный порядок, `max_size` — длинная сторона при уменьшении (0 — исходная), `pingpong` — туда и обратно.

Редактор сохраняет поле `project` с путём к `.pixel.json`. Проект содержит полное разрешение, слои, кадры и задержки; PNG может быть уменьшенной версией для рабочего стола. Переноси JSON-набор вместе с папкой `*_assets`.

Покой, ходьба и основные позы зациклены. Приземление длится один цикл. Уведомления управляются правилами; если отдельного клипа реакции нет, поверх пользовательского покоя отображается встроенный значок события.
