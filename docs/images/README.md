# Изображения README

`desktop-demo.gif` — запись работы приложения, предоставленная автором проекта.
Копия для README: 800×500, 331 кадр, полная длительность 34,8 секунды,
около 8,2 МиБ. Исходная запись 1920×1200 остаётся в корне проекта;
`/Запись-экрана-от-*.gif` исключены через `.gitignore`. Подготовленная копия
в этом каталоге должна входить в Git, иначе относительная ссылка GitHub не заработает.

`light.png`, `dark.png` и `workshop.png` — снимки интерфейса приложения.
`bunny-demo.gif` — пример анимации встроенного зайчика.

`pixel-desktop.png` и `pixel-workshop.png` — простые декоративные полоски
из оригинальных спрайтов приложения: заяц, рамки, сердечки и несколько кадров.
Нарисованы кодом на сетке 256×56 и увеличены ровно в четыре раза без сглаживания.
Это оформление README, а не снимки интерфейса. Генеративные иллюстрации заменены.

Перерисовать полоски из корня проекта:

```sh
.venv/bin/python scripts/render_readme_art.py
```
